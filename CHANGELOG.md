# HeroTweaker v0.9.3 — NVIDIA и новый бенчмарк

## Видеокарты

- Аудит NVIDIA дополнен чтением NVML, установленной вместе с официальным драйвером. Версия драйвера и объём VRAM дополняются значениями NVML, если Windows/реестр их не предоставил.
- В GPU-разделе NVIDIA показываются текущая загрузка, температура, мощность, частоты ядра и памяти, загрузка видеопамяти и вентилятора — только если драйвер поддерживает соответствующие счётчики.
- В статусе аудита указано, подключилась ли NVML. Поддержка GeForce различается по модели и драйверу; отсутствующие значения не подменяются оценками.
- Ручные NVIDIA-параметры не заявляются до наличия подтверждённого API и безопасных диапазонов.

## Бенчмарк

- Вместо выбора файла EXE можно выбрать уже запущенное приложение из списка окон и фильтровать список по названию.
- PresentMon и счётчики привязываются к выбранному PID, поэтому запись не переключается на другой одноимённый процесс.
- Перед записью предусмотрена 5-секундная пауза, чтобы вернуться из HeroTweaker в игру.
- В карточке каждого замера отображаются доступные средние метрики игры и системы: CPU, RAM, GPU-движки, VRAM, температура, мощность, частоты и вентилятор.
- CSV кадров и JSON-срезы телеметрии сохраняются в `%LocalAppData%\HeroTweaker\Benchmarks`.

## Ограничения и проверка

- NVML использует установленный NVIDIA-драйвер и не добавляет сторонний бинарник в пакет. Некоторые значения GeForce могут быть недоступны на конкретной карте или драйвере.
- NVIDIA read-only telemetry должна быть проверена тестером на его RTX-системе; локальная сборка и интерфейс проверяются на компьютере разработчика.

# HeroTweaker v0.9.2 — крупное обновление

HeroTweaker переходит от старой оболочки на новую рабочую среду для обслуживания Windows. Это крупное обновление приложения и способа его распространения.

## Интерфейс и системная сводка

- Новая оболочка React и Tailwind CSS внутри WPF/WebView2: переработанные разделы, навигация и адаптивная компоновка.
- Системная сводка показывает сведения, полученные от Windows: версию и сборку ОС, архитектуру, процессор, использование и объём памяти, плату и BIOS, видеокарту, драйвер и видеопамять, а также системный том.
- Обновлены тема, цвета и иконка приложения.

## Обслуживание Windows и дисков

- Переработаны категории системных параметров, описания, технические сведения, история операций и откат поддерживаемых изменений.
- DiskTree анализирует занятое место с навигацией по папкам, круговой диаграммой, кэшированием результатов и отменой сканирования.
- Добавлены пакетное удаление приложений и поиск остаточных данных для отдельной проверки перед очисткой.

## Видеокарты и бенчмарк

- GPU-раздел выбирается по обнаруженному оборудованию. Аудит показывает поддерживаемые Windows настройки, модель, драйвер и доступные сведения о памяти.
- Ручные AMD-параметры появляются только при обнаружении поддерживаемой версии ADLX и сообщённых драйвером возможностей. Ручное управление разгоном не применяется автоматически.
- Бенчмарк собирает длительность кадра и FPS через PresentMon вместе с доступными счётчиками процесса и системы: CPU, RAM, GPU, VRAM, температура, мощность и частоты. Неподдерживаемые счётчики помечаются как недоступные.

## Публикация и обновление

- Вместо одного большого EXE релиз поставляется ZIP-папкой `HeroTweaker-win-x64.zip` с приложением и runtime; установка отдельного .NET Runtime не требуется.
- Приложение проверяет SHA-256 загружаемого обновления, создаёт резервную копию текущей версии и поддерживает откат при неудачной установке.
- Автообновление предназначено для релизов с ZIP-asset. Переход с предыдущего single-file релиза `v0.8.9.1` на файловую публикацию выполняется вручную один раз.

## Установка

Скачайте `HeroTweaker-win-x64.zip` из Assets этого релиза, распакуйте в постоянную папку и запустите `HeroTweaker.exe`. Для интерфейса требуется WebView2 Runtime. Если Runtime отсутствует, приложение предложит установить его; потребуется интернет.

Изменения реестра и служб выполняются по действию пользователя. Перед рискованными системными изменениями рекомендуется создать точку восстановления.
