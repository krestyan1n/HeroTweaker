⚡ HeroTweaker
Большинство оптимизаторов Windows представляют собой «черные ящики»: они применяют скрытые скрипты, ломают службы обновлений и засоряют систему.

HeroTweaker создан системными инженерами по принципу открытости и максимальной производительности:

Никаких скрытых действий: каждое изменение снабжено двойным описанием — для обычных пользователей и детальной технической сводкой для профи.

Транзакционный журнал и Rollback: перед любым твиком создается снимок реестра/службы. Любое действие можно откатить в 1 клик.

Аппаратная скорость: отказ от медленных WMI и PowerShell команд в критических секциях в пользу прямого Win32 API (FindFirstFileExW, прямое чтение веток реестра, низкоуровневые сокеты).

🚀 Ключевые модули
1. ⚙️ Библиотека твиков ОС (71 системный переключатель)
Разделена на категории: Приватность, Производительность, Службы, Интерфейс и Обновления.

Двойное описание (Dual-Tier Why?):

👤 Обычным пользователям: человеческое объяснение, что именно изменится в работе ПК и играх.

⚙️ Для профи (Under the Hood): точные пути реестра (HKLM/HKCU), параметры DWORD/SZ, затронутые системные службы и подсистемы ядра (ntoskrnl, DWM, NDIS, ETW).

Ключевые оптимизации: удержание ядра Windows в ОЗУ (DisablePagingExecutive), снятие сетевого дросселирования (NetworkThrottlingIndex), мгновенный отклик меню (0 мс), отключение телеметрии Asimov/DiagTrack, возврат классического меню Windows 10.

2. 💾 Анализатор дисков DiskTree & Глубокая очистка
Сверхбыстрый Win32-сканер: параллельное чтение структуры каталогов с флагом ядра FIND_FIRST_EX_LARGE_FETCH с аппаратным задействованием глубины очереди NVMe SSD.

Двухуровневый кэш (L1 RAM + L2 Binary Engine):

L1 (Память): мгновенный отклик (0 мс) при переходах назад/вперед и навигации по хлебным крошкам.

L2 (Диск): компактные бинарные файлы .htc со структурой HTDC, считываемые за доли миллисекунды без парсинга тяжелого JSON.

Интерактивная Sunburst-диаграмма: многоуровневая визуализация структуры папок с плавной анимацией секторов и контекстным меню Проводника.

Disk Cleaner: очистка шейдерных кэшей DirectX/Vulkan/NVIDIA/AMD, отчетов об ошибках и временных файлов.

3. ⚡ Сеть, DNS Benchmark & Gaming Latency
Физический селектор адаптеров: автоматическая фильтрация виртуальных сетевых петель, Hyper-V и VMware — работа только с реальными картами (Ethernet / Wi-Fi).

Честный DNS-бенчмарк: гибридный замер задержки через прямой коннект к TCP-порту 53 (DNS) и ICMP Ping без зависания интерфейса.

Переключение в 1 клик: мгновенная смена DNS-сервера (Cloudflare, Google, Quad9, AdGuard, Яндекс) или сброс на DHCP.

Ultra Low Latency (Nagle Disabled): прямое управление параметрами интерфейсов TcpAckFrequency=1 и TCPNoDelay=1 для моментальной отправки сетевых пакетов в соревновательных играх (CS2, Dota 2, Valorant).

Сетевой доктор: сброс поврежденных сокетов Winsock и очистка локального кэша резолвера (ipconfig /flushdns).

4. 🛠️ Developer Doctor & PATH Inspector
Аудит окружения разработки: автодетект версий Git, Node.js, Python, .NET SDK, Docker, Rust, Go, Java.

PATH Doctor: сканирование системных и пользовательских переменных PATH с обнаружением битых каталогов, дубликатов и очисткой в 1 клик со снимком реестра для отката.

CLI Inspector («Кто владеет командой?»): определение исполняемого файла, который вызывается первым при вводе команды в консоли, выявление конфликтов версий.

5. 📱 Приложения, Драйверы & Toolbox
Каталог ПО (Toolbox): пакетная установка софта первой необходимости через Windows Package Manager (Winget).

Менеджер установленного ПО: просмотр и удаление сторонних приложений без вызова медленной классической панели управления.

Реанимация UWP: восстановление удаленного Microsoft Store и перерегистрация встроенных приложений Windows.

Бэкап драйверов: экспорт установленных OEM-драйверов в папку для быстрого восстановления после переустановки Windows.

🛡️ Безопасность и Rollback
Каждая операция с реестром и системными службами атомарно логируется в TransactionManager. Если после применения твика вы захотите вернуть стандартные значения:

Откройте вкладку «📋 История» в правом верхнем углу.

Найдите нужную транзакцию (содержит имя твика, точное время и снимок состояния).

Нажмите кнопку «↩️ Откатить» — параметры мгновенно вернутся в исходное состояние.
