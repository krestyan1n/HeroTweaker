# HeroTweaker

Локальная инженерная утилита для Windows 10/11: системные твики с журналом изменений, анализ диска, сетевые инструменты, работа с драйверами и аудит окружения разработчика.

HeroTweaker не выполняет действия в фоне: операции запускаются пользователем, а изменяемые параметры реестра и служб фиксируются в истории для последующего отката.

**Версия 0.9.3** — расширена NVIDIA-телеметрия через NVML, GPU-аудит точнее читает VRAM и драйвер, а бенчмарк выбирает уже запущенную игру и пишет кадры по PID вместе с расширенным отчётом нагрузки.

## Возможности

### Системные настройки и история

- Категории: приватность, производительность, службы, интерфейс и обновления.
- Описания изменений на понятном языке и технические детали там, где они доступны.
- История операций и откат поддерживаемых изменений.
- Создание точки восстановления и быстрый перезапуск Explorer.

### DiskTree и очистка

- Анализ занятого места на выбранном диске с интерактивной диаграммой и навигацией по папкам.
- Кэш результатов, отмена сканирования и безопасная работа с корнем диска.
- Открытие элементов в Проводнике, копирование пути и перенос в корзину.
- Очистка временных файлов и типовых кэшей.

### Сеть и задержки

- Выбор активного физического сетевого адаптера в компактном выпадающем списке; по умолчанию выбирается адаптер с маршрутом по умолчанию.
- DNS-бенчмарк через реальный UDP DNS-запрос; TCP и ICMP используются как резервные способы измерения.
- Быстрая смена DNS или возврат к DHCP.
- Инструменты очистки DNS-кэша, восстановления Winsock и настройки Nagle для выбранного сценария.

### Инструменты системы

- Поиск обновлений драйверов, экспорт и восстановление OEM-драйверов.
- Установка приложений через Winget и управление установленным ПО.
- Восстановление Microsoft Store и встроенных UWP-приложений.
- Developer Doctor: поиск SDK/компиляторов, проверка PATH и разрешение CLI-команд.

### GPU и бенчмарк

- Вкладки AMD и NVIDIA появляются по обнаруженным Windows видеоадаптерам.
- Аудит показывает прочитанные настройки Windows, сведения драйвера и профили приложений. На NVIDIA данные драйвера/VRAM дополнительно дополняются через NVML, если библиотека есть в поставке драйвера.
- NVIDIA NVML используется только для чтения: доступные на конкретной карте загрузка, температура, мощность, частоты и VRAM отображаются в разделе GPU. Возможности NVML на GeForce зависят от версии драйвера и модели; неподдержанные поля остаются пустыми.
- Профиль игры назначает ей режим высокой производительности через настройки Windows.
- Бенчмарк показывает список запущенных приложений с открытым окном, принимает выбранный PID и сам запускает PresentMon с 5-секундной задержкой, чтобы вернуться в игру. Ручной выбор EXE игры больше не нужен.
- Сравнение ДО/ПОСЛЕ показывает FPS, 1%/0.1% low, P99 и средние по CPU/RAM/GPU/VRAM/температурам/мощности/частотам/вентилятору. Это измеренные данные, не синтетическая оценка.
- Во время замера раз в секунду сохраняется телеметрия процесса и всей системы; GPU Busy из PresentMon также сохраняется как время работы GPU на кадр, а не процент загрузки. Исходные CSV и JSON остаются локально в `%LocalAppData%\HeroTweaker\Benchmarks`.
- Счётчики GPU и аппаратные датчики зависят от Windows, драйвера, прав доступа и конкретной видеокарты. Недоступные значения отображаются прочерком. Данные сессии сохраняются в JSON рядом с CSV.
- Проверка GitHub Releases доступна по кнопке в верхней панели. По отдельному нажатию «Скачать и установить» приложение скачивает ZIP релиза, сверяет SHA-256 с GitHub и применяет пакет после закрытия окна. Ошибка замены вызывает откат к копии прежних файлов.
- Для ETW-захвата запустите программу от администратора или добавьте пользователя Windows в группу `Performance Log Users`.

### Новая рабочая оболочка

- Интерфейс собирается из React-компонентов и Tailwind CSS и запускается локально в WebView2. Веб-страницы и сетевые ресурсы не требуются для работы интерфейса.
- На сводке показываются данные системного ядра; графики CPU и RAM используют историю реальных датчиков. DiskTree и доступные AMD ADLX-регуляторы подключены к существующим C#-командам.
- Остальные экраны пока доступны через прежние рабочие модули. Их перенос в новую оболочку будет идти поэтапно, чтобы не потерять уже реализованные действия.
- При старте приложение проверяет WebView2 Evergreen Runtime. Если Runtime отсутствует, оно предложит установить его: скачает небольшой официальный bootstrapper Microsoft, проверит Authenticode-подпись и запустит тихую установку. Отдельный PowerShell-скрипт не используется.

## Интерфейс

- Новая компоновка Workbench: сгруппированная боковая навигация, рабочая область и боковая аппаратная сводка.
- Интерактивный фоновый свет откликается на положение указателя; короткие переходы учитывают системную настройку сокращения движения.
- Кастомная верхняя панель и собственные кнопки управления окном.
- Телеметрия CPU/RAM, системная сводка и встроенные цветовые темы.

## Запуск

1. Скачайте `HeroTweaker-win-x64.zip` из раздела Releases и распакуйте один раз в отдельную папку.
2. Запустите `HeroTweaker.exe` из этой папки. Публикация self-contained: установка .NET Runtime не нужна. Приложению также требуется Evergreen WebView2 Runtime; если его нет, HeroTweaker предложит автоматическую установку от Microsoft.
3. Для операций, меняющих HKLM, службы, DNS или системные компоненты, приложение запросит права администратора.
4. Для обновления оставьте файлы в папке приложения и используйте кнопку «Обновления» в верхней панели.

## Системные требования

- Windows 10 x64 или Windows 11 x64.
- Для релизного EXE дополнительный .NET Runtime не требуется.
- WebView2 Evergreen Runtime для новой оболочки. В Windows 11 он обычно предустановлен; если его нет, для первого запуска потребуется интернет, чтобы загрузить bootstrapper и Runtime Microsoft.
- Интернет нужен для установки WebView2 Runtime при необходимости, а также функциям, которые обращаются к сети: проверка обновлений, Winget, DNS-бенчмарк и поиск драйверов.

## Безопасность

Сначала ознакомьтесь с описанием твика. Твики не являются универсальным способом ускорить любой ПК: эффект зависит от оборудования, версии Windows и конфигурации. Перед экспериментами создавайте точку восстановления и проверяйте запись в истории операций.

## Сборка из исходников

Требуются .NET SDK 10 и Node.js/npm.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Publish-Release.ps1 -Version 0.9.3
```

Скрипт собирает React/Tailwind интерфейс и файловую self-contained публикацию, архивирует её содержимое в ZIP с ожидаемым именем `HeroTweaker-win-x64.zip` и создаёт sidecar SHA-256. Для публикации обновления приложите ZIP как asset стабильного GitHub Release; GitHub API digest используется клиентом как авторитетная проверка целостности.

## Статус

Текущая версия: `0.9.3`.

PresentMon — проект Intel GameTechDev, распространяемый по MIT-лицензии. Уведомление и текст лицензии встроены в приложение.

LibreHardwareMonitorLib 0.9.6 используется без изменений для чтения аппаратных сенсоров. Библиотека распространяется по MPL-2.0; уведомление с лицензией и ссылкой на исходный код встроено в приложение.

NVIDIA NVML динамически загружается из установленного драйвера, если доступна; файлы NVML/NVIDIA SDK в пакет HeroTweaker не копируются.

**Переход со старого single-file EXE:** версию `v0.8.9.1` нужно было заменить вручную один раз на файловую публикацию `v0.9.2` или новее. В дальнейшем приложение может устанавливать обновления ZIP-релизов по кнопке.

Проект активно развивается. Идеи и сообщения об ошибках приветствуются в Issues.
