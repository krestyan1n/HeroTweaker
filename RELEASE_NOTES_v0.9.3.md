# HeroTweaker 0.9.3 — NVIDIA и новый бенчмарк

В этом обновлении NVIDIA-аудит получает телеметрию из установленного драйвера, а бенчмарк больше не требует вручную искать EXE игры. Программа показывает измеренные значения и не подменяет их синтетическими оценками или неподдержанными ползунками.

## NVIDIA GPU-аудит

- Считывает телеметрию NVIDIA через NVML, если библиотека есть в установленном драйвере.
- Дополняет отсутствующие сведения о драйвере и выделенной видеопамяти.
- Показывает текущую загрузку GPU, температуру, мощность, частоты ядра и памяти, использование VRAM, контроллер памяти и вентилятор — если конкретная карта отдаёт эти показатели.
- Аудит сообщает, удалось ли подключить NVML. Поддержка GeForce и отдельных счётчиков зависит от модели и драйвера; неподдерживаемые значения остаются недоступными.
- NVML используется только для чтения. Управление частотами и напряжением не появляется без подтверждённого API и диапазонов, предоставленных драйвером.

## Бенчмарк игр

- Выберите уже запущенное приложение с открытым окном вместо поиска его EXE на диске.
- PresentMon и счётчики процесса привязываются к PID — замер не перепутает игру с другим процессом с таким же именем.
- Перед записью есть пауза пять секунд, чтобы вернуться в игру.
- В результат добавлены средние значения по процессу и системе: CPU, память, GPU-движки, выделенная и общая видеопамять, температуры, мощность, частоты и вентилятор — если данные доступны.
- Недоступные метрики отображаются прочерком, без приблизительных оценок.
- CSV с кадрами и JSON-телеметрия с интервалом в одну секунду сохраняются локально в `%LocalAppData%\HeroTweaker\Benchmarks`.

## Примечания

- NVML загружается из установленного драйвера NVIDIA; библиотека не включена в архив релиза.
- Для захвата PresentMon нужен доступ к ETW. Если Windows отказывает, запустите HeroTweaker от администратора или добавьте пользователя в группу `Performance Log Users`.
- При отсутствии NVML программа использует доступные альтернативные счётчики. Реальные показатели NVIDIA нужно дополнительно подтвердить на разных видеокартах и драйверах.
